# FINCODE TEAM

Внутренняя презентация корпоративной спортивной команды ООО «ФИНАНСОВЫЙ КОД».

## Запуск

```bash
npm install
npm run dev
```

Сборка для GitHub Pages: `npm run build` — в корень копируются `index.html` и `assets/`.

## Замена фотографий

Файлы в `app/public/assets/`:

- `brand/` — логотип
- `sport/` — соревнования
- `teams/` — примеры команд
- `kit/` — мокапы формы
