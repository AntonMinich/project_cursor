# Состав. — презентация

Сайт-презентация из 5 слайдов: формирование спортивной команды в брендированных майках и джерси как способ вывести новую компанию на аудиторию.

Откройте `index.html` или опубликуйте корень репозитория на GitHub Pages.

Листать: стрелки, клик по краям, точки внизу, свайп на телефоне.
