# Презентация формы FINCODE TEAM

Презентация корпоративной спортивной формы как маркетингового инструмента ООО «ФИНАНСОВЫЙ КОД».

## Запуск

```bash
npm install
npm run dev
```

Сборка для GitHub Pages: `npm run build` — в корень копируются `index.html` и `assets/`.

## Замена фотографий

Новые картинки для агента кладите в **`image_Fincode/`**.

Загрузка на GitHub: https://github.com/AntonMinich/project_cursor/upload/main/image_Fincode

Готовые файлы презентации — в `app/public/assets/`:

- `brand/` — логотип
- `sport/` — соревнования
- `teams/` — примеры команд
- `kit/` — мокапы формы
