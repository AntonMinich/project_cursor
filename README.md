# 21 век finance × Фламинго Лизинг

Демо интернет-магазина смартфонов с сценарием консультации по лизингу «Фламинго». Реальные платежи, SMS-шлюз и заявки не подключаются.

## Запуск

```bash
npm install
npm run dev
```

Локальная сборка: `npm run build` и `npm run preview`.

## GitHub Pages

Сайт публикуется из корня ветки `main`. После изменений, которые должны попасть на сайт, выполните `npm run build` и закоммитьте обновлённые `index.html`, `assets/` и `.nojekyll`.

Демо: https://antonminich.github.io/project_cursor/

## Сценарий демо

1. Главная «21 век finance» — 5 карточек товаров и рекламный баннер «Фламинго — бери в лизинг».
2. Карточка товара — цена, описание, характеристики, кнопка «Купить» и блок «От N BYN/мес. с Фламинго».
3. Кнопка «?» открывает условия лизинга.
4. «Консультация» → форма (фамилия, имя, телефон).
5. Подтверждение номера. Тестовый SMS-код: **1111**.
6. Экран «Спасибо!» и возврат к карточке товара.
