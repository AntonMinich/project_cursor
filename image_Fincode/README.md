# image_Fincode

Сюда складывайте картинки для презентации формы FINCODE TEAM: логотип, фото, макеты.

Как добавить файлы:

1. Откройте загрузку на GitHub: https://github.com/AntonMinich/project_cursor/upload/main/image_Fincode
2. Перетащите изображения и закоммитьте в `main`.
3. Напишите агенту, какие файлы куда поставить.

Файлы из этой папки сами в слайды не попадают — их нужно встроить в презентацию.
